# 티켓시그널

이 저장소는 중간고사 MVP 제출 자료를 순서대로 정리하는 저장소입니다. 현재 단계에서는 기획 대비 구현 비교 문서를 게시하며, 애플리케이션 소스와 재현에 필요한 파일은 후속 단계에서 추가합니다. 아래 구현 상태는 기존 작업 프로젝트를 기준으로 설명합니다.

NOL 티켓, 티켓링크, 멜론티켓, YES24의 공개 오픈예정 공지를 수집하는 웹서비스입니다. 한국시간 오늘부터 13일 뒤까지 총 14일의 티켓 오픈 일정을 표시합니다. 선예매와 일반예매는 별도 일정입니다. 날짜 미정, 비공개, 원본에서 이미 제외한 일정의 완전성은 보장하지 않습니다.

이메일·관심 키워드·관심 목록은 아직 브라우저 localStorage 데모입니다. Gmail 서버 발송 모듈을 준비했지만, Google 인증 및 구독·예약 발송 연결은 완료하지 않았습니다. 실제 이메일은 발송하지 않습니다.


## 기획안과 현재 구현의 차이

기준일: 2026-10-26. 비교 대상은 「중간고사 MVP 기획안3 — 티켓 레이더」의 5개 슬라이드와 현재 소스입니다. 아래의 구현 상태는 코드 확인 기준이며, 실제 배포 환경에서의 최신 실행·수신 성공을 의미하지 않습니다.

- 공개 데모: https://ticket-signal.kmu-mba-1095.chatgpt.site
- 해결하려는 문제: 공연 관람객이 네 예매처를 각각 방문해 오픈 일정을 확인해야 하는 불편과 예매 일정 누락.
- 핵심 가치: 여러 예매처의 오픈 일정을 한 화면에서 확인하고 관심 아티스트의 일정을 놓치지 않도록 돕는 것.

### 평가 항목에 대한 현재 결론

‘기획안과의 차이’와 그 이유를 위 표로 정리했다. 다만 이 문서 작성만으로 핵심 기능 구현이나 검증이 완료되는 것은 아니다. 동일 공연 통합, 3일 필터·정렬, 실제 이메일 알림을 완성한 뒤 표를 최종 결과로 갱신해야 한다. 공개·재현에 필요한 LICENSE, .env.example, 독립 실행 확인 및 에이전트 작업 기록도 별도 후속 작업이다.
