## 판정의 범위

Google 인증과 기존 전송 모듈의 실제 API 발송 접수, 운영 서버의 설정 준비 상태를 확인했다. **사용자가 “잘 도착했다”고 응답해 테스트 메일 수신을 확인했다.** 이번 발송은 운영 웹서버의 발송 경로를 호출한 것이 아니므로 운영 서버에서의 종단 간 발송 검증으로 기록하지 않는다.

관심 키워드 구독의 서버 저장, 이메일 확인·구독 해지, 오픈 24시간 전 예약 발송, 중복 발송 방지 및 운영 발송 경로는 후속 작업이다. 현재 공개 구독 폼은 브라우저 데모이며 일반 방문자의 자동 메일 알림은 활성화하지 않았다. Google OAuth 앱의 Testing 상태에 따른 토큰 만료도 지속 운영 전에 점검해야 한다.

후속 구독·자동 알림 구현 및 검증은 [운영 이메일 기록](email-alerts-live.md)을 참조한다.
