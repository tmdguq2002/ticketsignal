# 실패 예매처 재시도

요청: 실패한 예매처만 일정 시간 후 다시 수집한다.

매일 한국시간 06시 전체 수집은 유지한다. 실패한 예매처는 마지막 시도에서 30분 뒤 재시도 대상이 된다. 재실패하면 60분, 다음 재실패면 120분을 기다린다. 자동 재시도는 최대 3회이며 이후 다음 정기 전체 수집까지 보류한다. 전체 수집 또는 수동 전체 갱신은 재시도 횟수를 초기화한다.

별도 예약 작업이 매시 45분에 대상 여부를 검사한다. 한국시간 05:45~06:15에는 재시도를 잠금 획득 전에 건너뛰어 06시 전체 수집을 우선한다. 따라서 최소 대기시간에 최대 약 1시간의 예약 간격이 더해질 수 있다. 예를 들어 06:00:35 실패는 06:30:35부터 대상이므로 06:45 실행에서 재시도한다. 성공한 예매처에는 요청하지 않고, 대상이 없으면 원본 사이트 요청·스냅샷 쓰기를 생략한다.

실패 시 해당 예매처의 마지막 정상 데이터를 유지한다. 성공 시 그 예매처의 데이터·성공 시각·상태만 교체하고 횟수를 초기화한다. 다른 예매처의 데이터·상태·마지막 성공 시각은 보존한다. 재시도로 전체 데이터가 새것처럼 보이지 않도록 전체 updatedAt은 유지하고 lastRetryAt을 따로 저장한다. 새로 발견한 상품의 firstSeenAt은 실제 재시도 시각을 사용한다.

일일 수집과 재시도가 동시에 R2 스냅샷을 덮어쓰지 않도록 D1에서 공통 잠금을 잡는다. 수집 요청은 총 3분 예산으로 제한하고, 잠금 만료 전인지 확인한 뒤 저장한다. 처리 중이면 겹친 호출은 건너뛴다. 잠금에는 10분 만료가 있어 중단된 실행이 영구 차단하지 않는다.

새 소유자 도구: retry_failed_ticket_openings. 메일을 발송하지 않는다. 요청한 실패 재수집만 수행하며 매시간 메일 예약은 그대로 유지한다. 사이트 원본의 423 등 오류가 계속되면 데이터 복구를 보장할 수 없고, 제한을 우회하지 않는다.
