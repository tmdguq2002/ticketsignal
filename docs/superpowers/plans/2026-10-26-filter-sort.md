# 3일 필터와 실제 정렬 구현

사용자가 승인한 3번 범위를 구현한다. Sites의 기존 R2 스냅샷을 유지하고 D1에 최초 수집 시각과 익명 브라우저 관심을 저장한다.

- [ ] 72시간 경계와 정렬, 서버 중복 집계·해제·최초 시각 유지 테스트 작성.
- [ ] 3일은 현재 이상 72시간 이하로 정의. 지난 일정은 제외. 오픈일순은 필터에 맞는 다음 오픈부터, 이미 열린 일정만 있으면 뒤로 배치. 관심 수·최신 등록순 동률은 다음 오픈일과 ID로 결정.
- [ ] D1 product_first_seen(source key, first seen), ticket_interests(browser id, source key) 복합 고유키. 하나의 통합 공연 내 여러 예매처 관심은 브라우저 DISTINCT로 집계. 동일 상세 URL의 판매 회차는 같은 source key를 사용.
- [ ] Cookie는 서버 발급 HttpOnly SameSite=Lax. 같은 브라우저의 반복 등록은 한 번만 저장하고 해제는 그룹의 모든 source key 삭제. Origin 검증과 서버의 현재 공연 목록으로 요청 검증. 사람 수·로그인 계정 수가 아니라 브라우저 기준임을 안내.
- [ ] 첫 수집 시각은 기존 스냅샷의 수집 시각을 초기값으로 사용하고 이후 갱신으로 덮어쓰지 않는다. source key가 바뀌면 새 항목으로 처리하는 한계를 기록한다.
- [ ] 서버 실패 시 관심 수를 임의 숫자로 표시하지 않고 집계 불가 안내. 저장 성공 후 UI 갱신. 기존 로컬 즐겨찾기를 자동 전송하지 않는다.
- [ ] 로컬 D1 마이그레이션·HTTP 중복등록/해제 테스트·모바일 브라우저·빌드 후 공개 배포와 GitHub 검증 문서 반영.
