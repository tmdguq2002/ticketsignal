# 동일 공연 통합 구현 계획

사용자가 승인한 2단계 범위: 같은 공연을 한 카드로 묶고 예매처별 개별 페이지와 선예매·일반예매 일정을 보존한다.

## 설계

원본 API 일정은 보존하고 브라우저의 순수 그룹 함수로 공연 카드를 만든다. 제목 유사도만으로 합치는 방식은 지역·시즌 오인 위험이 있어 사용하지 않는다. 동일 예매처·동일 상세 URL은 같은 상품의 판매 회차로 묶는다. 예매처 간에는 공지 접미사·장식 괄호·공백을 정규화한 제목과 일치하는 오픈 시각이 필요하다. 지역·연도·시즌 문구는 지우지 않는다. 알려진 공연장·공연 기간이 충돌하거나 연결 후보가 모호하면 원본 그룹을 유지한다. 공연 기간을 수집하지 못한 항목은 오픈 시각을 보조 신호로 사용하므로 모든 중복의 완전한 판별은 보장하지 않는다.

카드의 포스터·제목은 통합 상세를 열며 예매처별 일정 링크는 공식 개별 페이지로 이동한다. 필터는 원본 일정 단위로 일치 여부를 판단해 표시하되 상세는 통합 공연 전체 일정을 보여준다. 즐겨찾기는 기존 일정 ID를 유지하여 구형 저장 데이터도 작동한다. 3일 필터·정렬·실제 메일은 이번 범위에 포함하지 않는다.
