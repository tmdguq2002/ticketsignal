# 실제 이메일 구독과 알림 구현

승인된 범위: 이메일 확인, 키워드 서버 저장, 24시간 전 알림, 중복 방지, 해지, 실제 동작 검증.

설계: 기존 D1·Gmail API·Sites 예약을 재사용한다. 서버 구독은 확인 전 pending, 확인 후 active이며 변경은 이메일 재확인 후 반영한다. 랜덤 확인 토큰은 해시 저장하고 링크 fragment로 전달한다. 해지는 서버 비밀값으로 서명한 토큰으로 POST 처리한다. 개인정보는 구독 유지 동안 저장하며 해지 시 삭제한다.

- [x] 저장·확인·해지·한도·중복 발송 테스트부터 작성.
- [x] D1 추가 마이그레이션, 서버 모듈 및 HTTP API 구현.
- [x] 기존 구독 폼을 실제 API로 연결, 실제 동의·상태·해지 안내 수정.
- [x] 소유자 전용 알림 실행 도구와 매시간 예약 연결. 기존 06시 수집 유지.
- [ ] 테스트·로컬 HTTP·리뷰 후 배포, 운영 확인 메일과 수신자 확인으로 검증.

운영 규칙: 매시간, 열리기 전 24시간 범위 내 일정 중 미발송 건을 보낸다. 늦게 발견·구독한 일정도 다음 실행에 발송한다. 26시간 이상 오래된 스냅샷은 발송 보류. 메일은 하루 최대 200건(확인+알림), 확인 요청은 이메일별 10분 간격 및 IP별 시간당 5회. D1 원자적 claim으로 중복 실행을 막고 불확실한 전송은 재시도하지 않는다. 정확히 정각 24시간 전 전달이나 Gmail 수신함 도착은 보장하지 않는다.

확인 링크는 24시간 유효. GET 방문만으로 구독·해지를 수행하지 않고 확인 버튼의 POST로 처리한다. 메일 수신 확인 기록은 사용자 발언에 근거한다. 기존 브라우저 데모 구독은 자동 전송하지 않는다.

배포·46개 자동 테스트·9개 로컬 HTTP 검사·독립 리뷰·매시간 예약 활성화 완료. 운영 확인 메일을 요청했으며 사용자의 확인 버튼 클릭과 실제 공연 알림 수신 검증은 진행 중.
