# 공개 소스와 재현 환경 준비 계획

**Goal:** 제출 저장소에 전체 앱 소스와 실행 안내·라이선스·환경변수 예시를 공개한다.
**Architecture:** 기존 앱의 추적된 파일을 제출 저장소로 복사한다. 운영 비밀정보와 로컬 상태는 제외하고 별도 폴더에서 공개 파일만으로 검증한다.
**Tech Stack:** Node.js 22.13+, npm, Vite/vinext, Cloudflare 로컬 D1·R2.
**Spec:** 평가 항목 4: 공개 GitHub, README(문제·실행 방법), LICENSE, .gitignore, .env.example, 비밀정보 제외.

- [x] 추적된 소스 복사, 기존 제출 문서 유지, 필수 파일 작성.
- [x] 새 폴더에서 의존성 설치, 테스트, 빌드, D1 마이그레이션, HTTP 검증.
- [x] 실행 안내와 검증 결과 작성, 비밀정보·제외 규칙 검사.
- [x] GitHub 공개 대상과 공개 상태 확인. 커밋 후 푸시하고 원격 커밋을 최종 확인한다.

## 확인할 조건

외부 인증 없는 실행, 과거 스냅샷의 날짜 만료, 로컬 DB 초기화, Gmail 비활성 상태, 제삼자 이미지·코드 라이선스 구분을 문서와 실행 결과로 확인한다. 운영 서비스 배포나 이메일 연결은 변경하지 않는다.
